# Art. 32 Varianten
1
Variante Abweichung vom Beschäftigungsumfang gemäss Arbeitsvertrag Auswirkung auf Jahreslohn zusätzliche Kompensationsstunden
I minus 4 Std. minus 4 x 2.38 % keine
II minus 3 Std. minus 3 x 2.38 % keine
III minus 2 Std. minus 2 x 2.38 % keine
IV minus 1 Std. minus 1 x 2.38 % keine
V minus 1 Std. minus 2 x 2.38 % plus 42 Std.
VI keine keine keine
VII keine minus 1 x 2.38 % plus 42 Std.
VIII keine minus 2 x 2.38 % plus 84 Std.
IX plus 1 Std. keine plus 42 Std.
2 Wird Variante IX bei Teilzeitverhältnissen angewendet, so beträgt die Pluszeit eine Stunde mal reduzierter Beschäftigungsumfang. Die 42 Kompensationsstunden vermindern sich entsprechend.

# Art. 11 Annullation und Nichtbenützung
1 Erfolgt die Annullation für eine einmalige Nutzung spätestens zehn Tage vor dem Anlass, so werden keine Kosten verrechnet.
2 Erfolgt die Annullation kurzfristiger, so wird die volle Gebühr unter Vorbehalt von Abs. 3 in Rechnung gestellt. Das Gleiche gilt, wenn die Nutzung der Anlage oder des Anlagenteils ohne vorgängige Annullation unterbleibt.
3 Auf die Gebührenerhebung wird verzichtet, falls eine Ersatzbelegung gefunden werden kann.
